# Interfaces

## Unified experience
All interfaces use the same assistant and the same local chat history. You can
start in one place and continue in another.

## Command line (CLI)
- Use commands to start the web app or terminal app.
- Manage API keys and basic settings.
- Example commands: `agens start web telegram`, `agens tui`.

## Web app
- Runs in your browser.
- Shows responses live as they are generated.

## Terminal app (TUI)
- Runs inside your terminal window.
- Shows responses live with a full-screen interface.

## Telegram
- Chat with the assistant in Telegram.
- Responses may update the same message as the assistant is thinking.
