# Tools

## Files and folders
- Read a file (internal name: `file_read`)
- Write a file (internal name: `file_write`)
- Edit text in a file (internal name: `file_edit`)
- List folder contents (internal name: `list_directory`)

## Search
- Find files or folders by name (internal name: `find`)
- Search for text inside files (internal name: `grep`)

## Web
- Search the web (internal name: `web_search`)
- Read a specific web page (internal name: `web_fetch`)

## System
- Run a shell command when needed (internal name: `shell_command`)

## Schedule
- Add a reminder or event (internal name: `schedule_add`)
- List events for a time range (internal name: `schedule_list`)
- Update an event (internal name: `schedule_update`)
- Delete an event (internal name: `schedule_delete`)

## Settings
- Update your settings (internal name: `update_config`)
